## Compatibility
- Fixed for Sky PC **0.35.2** (build `0.35.2.426499`).
- The frame limiter signature is version-specific. After a game update, check
  the loader console for `[Out of 0] Unsupported Sky build` and rebuild with an
  updated signature if necessary.
